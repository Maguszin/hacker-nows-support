# Contributing

Thank you for taking the time to help improve Hacker Nows support process.

## How to contribute
You can contribute by:
- Reporting bugs
- Suggesting features
- Sharing reproduction steps
- Helping others in issues when appropriate

## Before opening an issue
Please:
1. Search existing issues
2. Use the correct issue template
3. Provide clear and complete details
4. Include screenshots, logs, or examples when helpful

## Writing a good bug report
A good bug report should include:
- A short summary
- What you expected to happen
- What actually happened
- Steps to reproduce
- App version
- OS/device/browser details
- Logs, screenshots, or recordings if relevant

## Writing a good feature request
A good feature request should include:
- The problem you are trying to solve
- Your proposed solution
- Any alternatives you considered
- Additional context or examples

## Be respectful
Please follow the code of conduct when participating in this repository.
