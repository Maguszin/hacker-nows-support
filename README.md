# Hacker Nows Support and Issue Tracker

This repository is used for:
- Bug reports
- Feature requests
- Usage questions
- General feedback

Please note:
- This repository does not contain the app source code
- Do not use public issues for security vulnerabilities
- Please search existing issues before opening a new one
- Please use the correct issue template so we can help you faster

## Before opening an issue
1. Search existing issues to avoid duplicates
2. Use the correct template
3. Include your app version and environment details
4. Include steps to reproduce the issue if applicable
5. Attach screenshots, logs, or recordings if helpful

## Support
If your question is not a bug or feature request, please use the Question / Support issue template.

## Code of conduct
Please be respectful and constructive. See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
