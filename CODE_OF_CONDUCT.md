# Code of Conduct

We want this repository to be a helpful and respectful place for reporting issues, sharing ideas, and asking questions.

## Expected behavior
- Be respectful and considerate
- Stay on topic
- Use clear and constructive language
- Search for duplicates before opening a new issue
- Provide enough detail for others to understand the problem

## Unacceptable behavior
- Harassment, insults, or abusive language
- Spam or flooding the repository with duplicate issues
- Posting private, sensitive, or malicious content
- Publicly disclosing security vulnerabilities instead of reporting them privately
- Harassing maintainers or other users

## Enforcement
Maintainers may:
- Close or lock issues
- Remove inappropriate content
- Request more information
- Refuse service to users who repeatedly violate these rules

## Reporting concerns
If you need to report behavior that violates this code of conduct, please contact the maintainers privately through the appropriate support or security contact method.
